
# interest-calculator

# GitHub Final Project

This project contains a Bash script to calculate simple interest based on user input.

## About the Project
The simple-interest.sh script calculates simple interest using the formula:
$$A = P (1 + rt)$$
Where:
- **P** = Principal amount
- **r** = Annual rate of interest
- **t** = Time period (in years)

## Usage
Run the script in your terminal using:
```bash
./simple-interest.sh
